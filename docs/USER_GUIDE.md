# 使用指南

[返回首页](../README.md)

## 选择前景色或背景色

左侧两个重叠色块分别表示前景色与背景色。点击色块切换当前编辑目标，选中色块会出现轮廓提示。

右侧色相条调整色相；主区域横向调整饱和度，自由选色模式下纵向调整 HSV 明度 V。拖动时预览颜色，松开后写入 Photoshop。


## 使用 LUT 模式

先选好一个起始颜色，再从面板菜单选择“切换 LUT 模式”。插件以当前灰度模型计算目标灰度，后续选色使用 LUT 提供的关系。

开启后，主区域的操作方式与自由选色不同：横向选择饱和度，明度由 LUT 计算。再次切换即可恢复自由选色。

## 配置辅助线

从面板菜单进入“设置”，开启“显示指示线”。也可使用菜单中的“显示/隐藏指示线”快速切换。

| 设置              | 作用                                   |
| ----------------- | -------------------------------------- |
| S 方向指示线数    | 沿饱和度方向划分主选色区域，范围 0–15  |
| 分别设置 S/V 线数 | 为两个方向使用不同数量；关闭时共用数量 |
| V 方向指示线数    | 设置水平线及等明度线的数量，范围 0–15  |
| Hue 方向指示线数  | 在色相条上显示分隔线，范围 0–15        |
| 显示水平线        | 显示固定 HSV 明度的水平线              |
| 显示等明度线      | 显示当前灰度模型对应的曲线             |
| 不透明度          | 分别控制水平线与等明度线的可见程度     |

水平线与等明度线至少保留一种类型。需要隐藏全部辅助线时，关闭“显示指示线”。

## 选择灰度模型

“颜色配置”提供默认、较亮、较暗、Dot Gain 15%、Gray Gamma 2.2 和自定义选项。其中 Dot Gain 15%、Gray Gamma 2.2对应 ps 的颜色校正选项，默认、较亮、较暗对应 ps 的黑白调整图层预设。

<!-- 图片就绪后，删除上方占位说明，取消下一行注释。
![颜色配置菜单中的灰度预设](images/settings-presets.png)
-->

选择“自定义”后，可调整 R、Y、G、C、B、M 六个色相锚点的灰度参数，分别对应 ps 的黑白调整图层的六个参数。

修改完成后点击“保存”。点击“取消”放弃本次修改；从菜单返回“色相立方体”也会还原未保存设置。
