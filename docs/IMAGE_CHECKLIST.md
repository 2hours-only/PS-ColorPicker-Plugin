# 图片制作清单

[返回首页](../README.md) · [发布准备](PUBLISHING.md)

所有素材放在项目的 `docs/images/` 目录。下表尺寸为导出建议，不要求改变插件实际面板比例；优先保证界面文字清晰，不要把低分辨率截图强行放大。

| 02 | `picker-overview.png` | 真实主面板，标注前景色、背景色、主选色区域、色相条和面板菜单；保留少量 Photoshop 上下文 | 宽 1000–1400px，高度按内容；PNG | README、使用指南共用 |

## 演示动图分镜

1. **0–2 秒**：显示主面板，选择起始色；光标短暂停留。
2. **2–4 秒**：展开面板菜单，点击“切换 LUT 模式”。
3. **4–7 秒**：缓慢拖动色相条，再横向调整主选色区域。
4. **7–10 秒**：松开鼠标，停留展示最终颜色和 Photoshop 前景色色块。

可以添加简短字幕“选择起始色 / 开启 LUT / 调整颜色”。保持录制连续，避免循环接缝让人误解操作先后。不需要配乐或声音。如果只制作静态图，可用三步拼图替代动图，并把两处引用统一改为 `lut-demo.png`。

## 统一视觉风格

- 所有截图使用同一 Photoshop 主题、系统缩放和插件面板尺寸；设置页可适当加高以展示内容。
- 从高分辨率原始截图裁切，避免 JPEG 压缩导致小字模糊。
- 画面主体是插件，尽量减少无关桌面与工具栏；主界面图保留适量宿主上下文。
- 标注统一使用一种字体和一种强调色；放在截图外侧，用细线指向目标，不遮挡控件。
- 对比图使用同一起始色和一致参数；标题准确说明改变了什么。
- 使用可公开的作品或空白画布；导出前检查文件名、账号和个人路径。
- 封面名称沿用当前 `LUT Color Picker`，若改名，请同时更新文档标题。

## 图片完成后如何接入

每个预留位置包含一段“图片待补充”说明，下面是已经写好的、暂时被 HTML 注释包住的 Markdown 图片引用。

1. 将图片按表中名称放入 `docs/images/`。
2. 删除对应的“图片待补充”说明。
3. 删除包住图片引用的 `<!-- … -->` 注释标记及提示文字，保留 `![说明](路径)` 这一行。
4. 对于 02 和 03，同时更新 README 与使用指南里的位置。
5. 若不制作可选封面，直接删除 01 的整个占位块，保留 README 标题即可。
6. 预览 GitHub 页面，检查图片大小、文字可读性和动图播放。

例如，主界面图片在 README 中的正式引用为：

```markdown
![插件主界面与主要操作区域](docs/images/picker-overview.png)
```

在使用指南中则为：

```markdown
![插件主界面与主要操作区域](images/picker-overview.png)
```

旧版 `cover.svg` 和 `workflow.svg` 已停止引用，不需要照着它们制作。
