# 发布准备与配图清单

此文件用于维护与发布准备。

## 图片准备

所有图片由作者制作，页面已预留对应位置。具体内容、建议尺寸与文件名见[图片制作清单](IMAGE_CHECKLIST.md)。

当前占位采用可见说明与注释中的 Markdown 图片引用，不会请求尚不存在的图片。完成后按清单说明替换。旧版 `docs/images/cover.svg` 和 `docs/images/workflow.svg` 仅为早期草稿，现已停止引用，不作为正式配图。

## 公开前确认

- 确认插件名称、作者、仓库名称，以及是否公开。
- 填写实际测试的操作系统、Photoshop 版本和安装方式。
- 由作者选择许可证；核实 LUT、图标与 sentence 文本的来源及可分发权限。
- 当前插件 ID 为 `com.rax.lutpicker`。如果未来修改，需同步 manifest、面板入口和已安装登记，并验证升级行为。
- 补齐真实截图与演示动图。
- 在 GitHub 上预览 README，检查图片、相对链接和手机端阅读效果。

## 推荐上传范围

运行文件：`manifest.json`、`index.html`、`index.js`、`style.css`、`asset/`、`images/`、`sentence/`。

文档：`README.md`、`docs/`。开发工具如需公开，先检查内容与用途，再单独纳入。

历史快照、打包文本及零散实验文件先保留在本地，不作为第一次公开上传的默认内容。正式安装包只包含运行所需文件。

## GitHub 发布步骤

1. 确认目标账号和仓库，准备本地 Git 仓库并检查首次提交文件列表。
2. 提交文档和插件源码；推送至确认好的 GitHub 仓库。
3. 使用 UXP Developer Tool 打包，并在实际 Photoshop 环境验证安装与主要操作。
4. 创建与实际版本一致的 tag 和 GitHub Release，附安装包、版本说明、已测试环境。
5. 将 README 的发行版入口和安装说明更新为真实 Release 链接。

不要在安装包、仓库或截图尚未存在时添加虚假的下载、构建通过或兼容性徽章。
